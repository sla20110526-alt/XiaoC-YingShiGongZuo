# 已确认镜头表达核对｜联调候选

本候选只用于隔离联调，未获准进入正式共享库，不自动加载到真实项目。不以本次文本装配结果宣称视频效果已验证。

输入：当前有效分镜、原台词及说话者、明确身份映射、既定状态的性质与程度、实际平台引用和模板限制。继承原执行单元已确认的模型、时长与范围。

执行：将叙事解释与生成正文分开；只在唯一身份可确定时替换叙述代词，原台词保持逐字不变。文学描述有明确可见状态时保留该状态，不创造颜色动画或动作；含义无法确定时返回原执行单元处理。固定生成限制与摄影指令仍按该项目有效模板保留。

输出：表达问题、已有依据、等价改写及未能解决的具体缺口。正式 Prompt 由视频生成综合执行按自己的格式整合，本候选不改镜头设计、不替换模型、不决定新版模板。

案例与验证：依据隔离样例 S10/S11 的文字分镜与正式 Prompt，验证了象征说明分离、原台词保留和持续苍白状态表达。本例没有成功视频、实际素材与生成记录，无法证明该方法降低模型误生成的效果；推广到其他状态与模型需要真实案例验证。
