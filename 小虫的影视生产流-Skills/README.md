## 现在怎么用

在项目任务中直接说明要启动的岗位和工作，例如：

> 在当前任务启动小虫的影视生产流总控。项目是……，这次需要……，资料在……。

> 在当前任务启动场戏设计综合执行，处理……场次，沿用这些已确认资料……。

> 启动视频生成综合执行，把这份已确认分镜按 Seedance 2.0 全能参考模式装配为正式 Prompt。

不必先启动全部部门。“启动某岗位”默认在当前任务承接；需要新任务时明确说“创建新任务”。其他项目任务也可使用这些用户级入口，读取的仍是本电脑这份正式规范和共享库。

执行单元按自己的条件询问是否需要专业能力。确认需要后，进入专业控制部查询共享库，展示具体候选；你选择准确版本及作用范围后，实际读取并回到原执行单元继续。既有选择在同一有效范围内沿用。Seedance 视频装配不追加通用大师询问；H3 官方源文件仍待适配。

这里的岗位调用由当前 Codex 读取文件并依照规则执行，没有后台跨任务管理程序。其他任务的情况仍需你回传，或明确指定要读取的任务与资料。共享能力也不会因为安装而全部加载。
