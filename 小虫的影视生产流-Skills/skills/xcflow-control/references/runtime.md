# 运行与衔接说明

本包为“小虫的影视生产流”22 岗位本地接入版 1.0.1。实际工作由当前 Codex 读取岗位 Skill 和所需文件后完成；没有额外后台服务或自动跨任务管理进程。

## 入口与范围

按用户请求选最小必要岗位，可从任意岗位开始，不要求先跑完整生产链。只有分配或推荐任务时不推定已经授权其具体执行；用户已明确要求启动或完成的范围持续执行，不重复请求许可。要转入已获授权岗位，实际读取[岗位清单](roles.md)中的目标 SKILL.md 及适用规范，然后承接任务。

原任务内返修留在原执行单元；新资产、新交付、新范围或跨单元需求回对应分控，跨分支由生产控制部协调。共享专业支持始终回原执行单元最终整合。普通交付可附引用，不自动登记、建版本或存项目历史。

只依据当前任务、用户回传以及用户明确指定并实际读取的任务或文件工作。用户要求查某任务时，按范围使用当前可用的任务读取工具；要求创建新任务时才调用创建工具；排队、已创建、资料已写入和已执行分别报告。工具不可用或路径不可读时给出可用交接文本及具体缺口，不假装已经传递。

## 冻结规范与本地绑定

70 份冻结文件保持原位原字节，22 份入口按需引用。文件准确路径与冻结校验值见 [bindings.json](bindings.json)。本包依赖当前电脑中这份规范和共享库；移动目录或换电脑后运行仓库根目录的安装工作流.py，自动重新绑定、检查和安装，不能把旧电脑绝对路径当已交付资料。目录定位失败时只报告缺口，不搜索旧系统代用。

冻结页头记载的是 2026-09-05 冻结时的部署情况；当前安装状态以接入回执为准。变更冻结业务条款仍须按用户明确修订范围处理，安装不会改写这些条款。

SKillXC 的 30 个旧版生产与控制 Skill 继续封存。共享库原文收存内容中的旧阶段、旧 Skill 名称、空间圣经等仅为来源历史，不能成为新版生产门禁、依赖或调用指令。复用其专业方法时服从用户当前决定、本系统岗位边界和有效项目事实。Profile 的适用范围及证据限制继续保留；不得因接入而提高证据等级。

## 共享能力

执行单元询问 → 用户确认需求 → 专业控制部查询共享库 → 用户选择 → 实际读取指定版本及必要配套 → 原执行单元继续。查询不是加载；程序返回正文后，当前实际应用方仍需读到与本次任务相关的必要内容，截断时继续分段读取。未选择的独立能力不得随配套文件暗中加载。

待适配 H3 源文件只作储备；Seedance 不增加通用大师询问。无合适共享项时不从空清单要求选择；基础输入足够则按本岗位继续，真实缺口只暂停相关部分。
