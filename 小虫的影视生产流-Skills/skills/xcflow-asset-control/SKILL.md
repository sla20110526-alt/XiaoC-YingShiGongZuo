# 小虫的影视生产流｜资产生产分控

这是新系统的本地接入入口。按当前任务使用以下冻结规范；本入口摘要不替代正文。规范页头的“尚未安装”记录的是冻结当时状态，当前安装状态见本包接入回执。

## 读取与执行

首次进入本系统或跨岗位承接时读取[运行与衔接说明](../xcflow-control/references/runtime.md)。先按岗位职责界定本次范围；实际执行前读取执行流程的适用部分和输出约定，交付前按该约定核对。长文可分段读取，不能把截断内容当作读完；局部任务不启动无关模块。

- [岗位职责](<../../../影视生产系统规范/规范整合稿_2026-09-05/资产生产分控/岗位职责.md>)
- [执行流程](<../../../影视生产系统规范/规范整合稿_2026-09-05/资产生产分控/执行流程.md>)
- [输出约定](<../../../影视生产系统规范/规范整合稿_2026-09-05/资产生产分控/输出约定.md>)

依据已确认类别、上游结果与生产前提分派。原资产任务内返修留在原执行单元；新增资产、新交付、新范围或跨单元需求回到分控。汇总问题不等于获准修订 Skill。

用户只要求启动本岗位时，默认在当前任务承接；目标和必要资料明确就继续。要求激活文本时给完整可复制指令；明确要求创建新任务时才使用可用创建工具。缺口只暂停受影响部分，已有决定直接继承。所说“读取”“创建”“保存”必须有相应实际操作。

## 条件引用

- 涉及启动或交接时，读取[任务启动与交接](<../../../影视生产系统规范/规范整合稿_2026-09-05/通用约定/任务启动与交接.md>)；其他岗位真实入口见[岗位清单](../xcflow-control/references/roles.md)。
- 涉及共享能力时，按本岗位已有入口条件读取[共享能力调用](<../../../影视生产系统规范/规范整合稿_2026-09-05/通用约定/共享能力调用.md>)，进入[专业控制部](../xcflow-professional-control/SKILL.md)。用户选定准确版本和范围后才读取能力；已有选择仅在原有效范围沿用。最终成果由原执行单元整合。
- 涉及资产身份、参考或平台映射时，读取[资产身份与引用](<../../../影视生产系统规范/规范整合稿_2026-09-05/通用约定/资产身份与引用.md>)。未有正式命名不阻止凭真实文件制作；正式 Prompt 的实际平台引用缺口须明确指出。
