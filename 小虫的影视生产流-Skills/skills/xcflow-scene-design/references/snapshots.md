# 完整锚点保存与恢复

按当前执行单元的冻结输出约定形成完整快照。模块结果、事实、冻结事项、用户决定、已有准确版本选择、模块状态、当前设计、待解决问题和版本信息都应保留；未执行部分标为未形成。场戏和分镜采用各自规定的锚点标题与字段，工具不另设统一业务模板。

已有项目保存位置直接沿用；默认当前任务可输出完整快照，不为保存而强建登记体系。文件输出时，将完整正文写入当前任务临时文件，然后执行：

```text
python scripts/snapshot.py --source <完整快照文件> --target <本次版本的实际保存路径>
```

从本 Skill 目录运行，或使用脚本绝对路径。每次业务更新用规范规定的下一版本；旧版不覆盖。同版本同内容允许核验沿用，不同内容返回冲突。成功时返回实际保存位置、校验值及完整回读正文；当前单元实际读到完整内容后，从锚点记录的模块与状态继续。

工具只保证文件保存与回读一致，不会替代设计完整性检查。输出被截断时从返回路径分段读完。无法写文件时直接在当前任务输出完整快照，不能只给一个不存在的路径。恢复任务必须读取用户指定或当前有效的真实快照，不以模糊记忆代替。
