# 输出与回传

## 每次运行产物

- 本次实际使用的预演配置。
- 独立 Blender 工程。
- 本段预演视频；需要时提供逐镜视频。
- 用于检查构图和动线的关键帧或联系表。
- 结构化场景报告。
- `previz-manifest.json` 运行清单。
- `previz-report.md` 镜头验证报告。

## 对话交付

优先说明：

1. 本次预演的镜头编号与局部范围。
2. 实际读取的分镜、资产与版本依据。
3. 人物站位与动线结论。
4. 构图、景别、机位和运镜结论。
5. 已完成的实现修正或技术调整。
6. 需要用户决定或返回分镜设计的问题。
7. 当前有效运行编号及产物位置。
8. 未验证内容和代理模型限制。

## 回到分镜设计

需要修改创作内容时，返回：

- 原镜头编号。
- 问题发生的帧段或动作节点。
- 预演中可观察到的现象。
- 对人物站位、动线、构图或运镜的影响。
- 建议修改方向和保持不变的范围。
- 对应预演视频、关键帧和运行清单位置。

只有用户确认并由原分镜执行单元更新最新锚点后，修改内容才成为正式分镜依据。

## 作为视频模型参考

预演视频默认标记为：`camera_blocking_reference`。

运行清单同时记录：

- `reference_use`：允许参考的机位、人物动线、节奏或空间关系。
- `must_preserve`：最终人物、场景、道具、画面风格及其他正式资产依据。
- `do_not_inherit`：代理形体、预览材质、预览灯光和未完成动作。

本地视频可以先作为设计依据。需要在外部平台直接调用时，必须取得真实平台引用名并核对具体文件；不得从本地文件名推造 `@` 引用。
