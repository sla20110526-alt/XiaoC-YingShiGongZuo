# 小虫的影视生产流

这是“小虫的影视生产流”的完整可安装仓库，供另一台工作电脑使用。当前接入版为 **1.0.1**，业务依据为 2026-09-05 已正式冻结的规范。

## 在工作电脑启动

下载或克隆本仓库，在 Codex 中打开仓库文件夹，然后发送：

> 请读取本仓库的 AGENTS.md 和《启动工作流.md》，检查完整文件并按指南完成本机安装或路径重绑，然后在当前任务启动“小虫的影视生产流｜总控”，等待我提交项目需求。沿用冻结规范和共享库准确版本，保持旧 SKillXC 的 30 个旧版 Skill 封存。

完整首次启动指令及操作方法见 [启动工作流.md](启动工作流.md)。安装需要本机 Codex 和 Python 3.10 或更新版本。Windows 也可运行根目录的 `安装到这台电脑.ps1`；安装程序不需要额外 Python 库。

## 跨电脑使用方式

仓库里的岗位入口使用相对路径，直接读取也能定位相邻的规范与共享库。安装程序按这台电脑的实际仓库位置生成安装入口与绑定文件，安装到 `CODEX_HOME/skills`，没有设置 CODEX_HOME 时使用用户目录中的 `.codex/skills`。

安装只处理 22 个 xcflow 岗位，不安装共享库里未被用户选择的独立专业能力，不修改宿主配置或旧版禁用状态。重复安装不重写相同文件；现有本系统安装需要更新时先备份。移动仓库或更换电脑后重新运行安装即可重绑。安装后请保留本地完整仓库，岗位需要按需读取其中的规范和能力。

获取更新后先检查再安装；已有项目继续使用原选定共享能力版本，不自动换成新版。

原本机接入完成了 25 项文件行为检查及关键文本情境联调。本跨电脑版另通过 11 项隔离验证，覆盖不同中文路径、用户目录、重复安装、重绑、备份、共享库读取、冻结校验和 Codex 实际发现 22 个入口。

这些是在当前电脑的隔离环境完成的测试，不代表已经远程安装到你的工作电脑。工作电脑状态以本机安装回执和实际读取为准；历史报告中的家里电脑路径只用于追溯，不是新电脑运行入口。真实模型出片效果仍需按项目实际素材与结果验证。
