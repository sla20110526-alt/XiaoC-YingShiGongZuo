# 镜头验证

## 第一优先级：人物站位与动线

- 开始与结束位置是否符合分镜。
- 关键动作发生时人物是否位于正确空间和画面区域。
- 移动路径是否穿墙、穿道具、相互穿插或超出可用空间。
- 人物距离、身体朝向、视线和出入场方向是否成立。
- 前后镜头需要连续时，结束状态与下一镜开始状态是否一致。
- 路径速度与镜头准确时长是否合理；代理动作无法证明的部分明确标为待验证。

## 第二优先级：构图与镜头

- 主要人物是否入画，头顶、脚部和关键动作是否被意外裁切。
- 实际画面是否达到分镜要求的景别和主体占比。
- 人物、道具与背景遮挡是否服务镜头任务。
- 机位、焦段、角度、视点和画幅是否与分镜一致。
- 轴线、视线方向和银幕运动方向是否在当前镜头段成立。
- 运镜是否存在穿模、越界、突然加速、错误跟随或看不到关键动作的问题。

## 检查方式

必须同时使用：

1. 配置、摄影机、关键帧、帧段和对象位置的结构化检查。
2. 实际预演视频或关键帧的视觉检查。

只完成脚本运行不能报告“镜头验证通过”。如果只验证了站位和动线，就只报告该范围，不把它扩大为灯光、表演细节或最终生成效果验证。

## 问题分类

- **实现错误**：配置、脚本、模型、关键帧或输出与既有分镜不一致。在本任务内直接修正。
- **技术可行性问题**：既定设计落地时出现穿插、空间不足、目标丢失等问题。提供最小技术调整并说明影响。
- **创作设计问题**：需要改变行为、镜头任务、景别意图、焦段意图、顺序或时长。报告问题和可选方向，等待用户决定或回到分镜设计。
- **资料缺口**：缺少会改变判断的空间、资产或动作依据。只暂停受影响的检查项目。
