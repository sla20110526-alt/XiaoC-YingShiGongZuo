# 《釜山行》电影形式 Profile

把影片中可迁移的形式动作编译进原创任务，不复刻原片剧情、人物、台词、专有场面或署名身份。

版本：**1.0**。本项为导演分类下的综合专业 Skill；内附 Profile 随本项使用。版本来源与适配说明见 [SOURCE.md](SOURCE.md)。

## 适用门槛

通过专业控制部候选清单被用户选定，或用户明确点名本 Skill 时，读取用户选择的版本。已有选择仍在有效范围内时沿用。

场景包含 `空间瓶颈`、`群体/传染性威胁`、`必须付出代价的伦理选择` 中至少两项时，可作为候选；适用性匹配用于推荐，实际使用依照用户选择。

泛动作设计、纯世界观讨论、影视事实问答、仅要求一张静帧图，或与当前锁定风格冲突的内容，应向原执行单元说明适用范围。按当前任务选择实际适用的规则。

## 与原执行单元衔接

在当前项目对话中承接需求，继承入口提供的项目与任务、当前工作环节、原执行单元、交付格式、指定版本和作用范围，以及已确认的脚本、空间、分镜、资产引用、时长、模型与模式。

- 只加载当前环节适用的规则，交付“规则 → 当前项目中的应用 → 对应任务或镜头引用”。
- 在导演、摄影、灯光、表演、剪辑或动作设计环节，提供该环节范围内的方案或修改建议，由原执行单元按既定格式写入项目成果。
- 在正式 Prompt 装配环节，只转译已确认的镜头内容，继承目标模型与模式。发现需要改变已确认镜头的内容时，列为修订建议交回原执行单元处理。
- 声音设计、配乐、对白声音、拟音和音频 Prompt 不属于本版交付。已有项目声音要求由原执行单元继续处理，本 Skill 不改动这些要求。
- 项目与成果引用沿用现有标识。加载与交付信息随本次结果提供，供原执行单元按既定登记方式衔接。

## 输入与模式

先识别交付模式：

- `PLAN`：提供当前专业环节所需的导演、摄影、灯光、表演、剪辑或动作设计方案。
- `MAKE`：提供原执行单元需要的镜头设计或画面表达内容，衔接其既定分镜表或 Prompt 格式。
- `REWORK`：诊断并局部修正已有方案。
- `CHECK`：按质量门槛检查是否落地。

先从已有项目依据中提取交付格式、预计时长、空间/路线、人物关系、威胁规则和锁定限制。影响本次专业判断的缺口返回原入口补充。用户要求探索性方案时，可以明确列出供选择的设想；正式交付使用已确认依据，不把设想写成项目事实。

## 选择规则而非堆叠规则

先阅读 [references/decision-qa.md](references/decision-qa.md) 的“规则选择器”，再只读取 [references/style-profile.md](references/style-profile.md) 中被选中的规则。

- 30 秒以内：1–3 条规则；30–120 秒：2–4 条；更长序列：3–6 条。
- 每条已选规则都必须写出当前场景的“触发 → 动作 → 可见效果”；没有触发就不调用。
- 在当前任务允许修改的范围内，依次遵循用户已确认要求、项目依据、空间与叙事可读性、Profile 美学。
- 若目标、路线或威胁已经完全公开，优先 P02 的地理可读性，不用 P08 继续遮掩。
- 只有用户需要时才查 [references/evidence-ledger.md](references/evidence-ledger.md) 的时间码与置信度；不要把研究数据搬进普通交付。

按模式读取 [references/production-recipes.md](references/production-recipes.md) 的对应模板，并在交付前执行 [references/decision-qa.md](references/decision-qa.md) 的 QA 与返工路径。

## 输出原则

- 先给场景目标与空间规则，再给镜头、光色、表演和剪辑。
- 把门、玻璃、窗、通道、车辆和人群当作关系结构，不当作装饰。
- 动作段先建立路线与障碍，再进入近身混乱，关键决定后重新确认地理。
- 快慢剪辑随威胁与道德选择调制；不要全程同速。
- 近景用于选择、羞耻、恐惧和牺牲的转折，不平均分配；没有行为积累时不强行煽情。
- 色彩服务空间与叙事规则：制度空间偏冷，短暂安全或亲密可偏暖，高潮可用高亮或低照度形成状态切换。
- 表演由呼吸、眼神、身体负荷、保护性接触和动作迟疑推进；极端肢体异化只用于感染或身体失控。

## 硬边界

- 不复制原片角色、情节链、对白、标志性构图组合或连续镜头顺序。
- 不把硬字幕、网站水印、片源压制痕迹、字幕字体当作美学特征。
- 不宣称“奉俊昊/延尚昊本人会这样做”或代表创作者本人。
- 不把普遍类型技巧包装成独有风格；每条建议必须说明为什么适合当前场景。
- 本版采用可见动作、空间、构图、光色与画面节奏方法；不以声音补位扩展交付范围。

## 交付最低要求

按模式给出可用产物，而不是固定套同一套标题：

- 共同交付：本 Skill 名称与版本、原执行单元、当前作用范围、已选规则和相应项目引用。
- `PLAN`：与当前环节有关的场景目标、已确认空间/威胁规则、专业方案及制作条件。
- `MAKE`：按原执行单元要求给出节拍或时长、画面/机位、走位或屏幕方向、光色状态、剪辑目的等相关内容；正式分镜和 Prompt 由原执行单元按既定格式承接。
- `REWORK`：优先列出决定性问题、局部修改建议和预期效果，由原执行单元在本次授权范围内处理。
- `CHECK`：列出适用检查项的结果、依据和需要返回处理的环节。方案检查与实际成片验证分别说明。
