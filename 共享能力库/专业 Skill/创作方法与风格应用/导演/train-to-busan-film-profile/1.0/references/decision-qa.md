# 规则选择器与执行 QA

## 规则选择器

先根据任务结构和原执行单元的当前作用范围选规则，再读取 `style-profile.md` 中对应的 P 条目。Prompt 装配任务只应用已确认镜头中的内容。P08、P12 在 1.0 中仅采用可见线索；声音建议已排除。

| 当前任务特征 | 选择 | 不选择 / 条件 |
| --- | --- | --- |
| 追逃、营救、多障碍移动 | P02；如有节奏转折再加 P03 | 目标已公开时不要加 P08 |
| 门、闸机、舱门等决定通行或代价 | P01 | 没有真实通行压力时不用 P01 |
| 危险尚未被角色理解 | P08 | 已公开追逐优先 P02 |
| 狭长/重复空间需要压迫或信息延迟 | P07 | 开阔空间不模拟车厢透视 |
| 群体出现阵营、排斥或意见扩散 | P05 | 人物少或立场未分化时不用 |
| 人物承担代价、压住恐惧、关系改变 | P04；有明确关系弧时才加 P10 | 没有行为积累时先设计行为，不调用情绪近景 |
| 感染或生物性失控 | P09 | 一般敌人、机械或自然灾害不用 |
| 安全、可见性、权力或记忆发生状态切换 | P06 | 不因类型标签强加冷色 |
| 灾难规模和个体选择必须同时成立 | P11 | 小规模双人戏不用 |
| 结尾有“身份被误判”的结构且已有可见前置线索 | P12 的视觉适配 | 不新增声音信号，不用作临时救场 |

### 最小集与优先级

- 先选一个解决“看得懂”的规则：通常 P02、P01 或 P07。
- 再选一个解决“为什么在乎”的规则：通常 P04、P05 或 P10。
- 最后按需要选一个控制状态或节奏的规则：P03、P06、P08、P09、P11、P12。
- 30 秒以内最多 3 条；30–120 秒最多 4 条；更长序列最多 6 条。超出上限必须说明每条新增的独特作用，否则删减。
- 优先级：用户锁定要求 > 原创与安全边界 > 路线和因果可读性 > 情绪因果 > 色彩/风格化。

## 输入不足的处理

| 缺失项 | 处理 |
| --- | --- |
| 时长、交付格式、模型或模式 | 先继承项目已确认信息；影响本次交付的缺口返回原入口补充。 |
| 空间路线 | 动作依赖路线时读取已确认空间依据；仍不足则提出具体缺口。探索性任务可列出供选择的空间设想。 |
| 威胁规则 | 使用项目已确认规则；影响判断的缺口返回原入口，不用假设替换项目设定。 |
| 群体/关系 | 没有相应依据时不调用 P05/P10，使用已有依据支持的规则。 |
| 用户锁定风格冲突 | 列出冲突，用户风格优先；本 Profile 只贡献不冲突的结构规则。 |

## QA 与返工路径

对当前可检查的计划、分镜或画面表达建议检查，按适用项输出结果和依据。失败项标明相应规则与局部修复建议，交回原执行单元处理。

| 检查项 | 通过条件 | 失败时返回 |
| --- | --- | --- |
| 用户约束 | 格式、时长、平台、锁定元素均可逐项定位 | 输入与模式 |
| 交接范围 | 结果对应原执行单元的当前任务，正式分镜和 Prompt 沿用其既定格式 | 原执行单元确认当前作用范围 |
| 版本与专业范围 | 使用选定的 1.0 版本；交付不含声音设计建议 | 删除声音补位，回到已选专业范围 |
| 空间与连续性 | 每次关键移动都有起点、目标、障碍；屏幕方向或替代路线不矛盾 | P02/P07 或镜头表 |
| 信息控制 | 遮掩、揭示、反应镜头均改变观众或角色已知信息 | P08 或删镜头 |
| 情绪因果 | 近景、停留或牺牲前有对应行为积累 | P04/P10 或重写动作 |
| 影调状态 | 每次冷暖/亮度变化对应安全、权力、可见性或记忆变化 | P06 或删去变化 |
| 节奏 | 每一次快切、停留、宽景复位都对应威胁、目标或情绪变化 | P03/P02 或调整节拍 |
| 原创边界 | 不含原片角色、情节链、对白、连续镜头顺序、水印/字幕特征 | 删除并以结构动作重写 |
| 平台可用性 | 使用项目已选模型与模式，准确转译已确认镜头，技术规格有依据 | 返回原入口补充依据或处理修订建议 |

方案级检查不等于验证拍摄或生成结果。若用户提供成片、分镜图或生成结果，可基于实际画面再做一轮 `REWORK`；未见结果时不得宣称画面已达标。
