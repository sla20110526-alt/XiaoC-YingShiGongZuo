# 电影形式 Profile

## 总纲

把封闭空间的物理规则、群体伦理和亲密关系组织成影像方法：空间先可读，威胁再侵入；身体动作制造情绪，选择改变构图；节奏在突袭、喘息、争执和牺牲之间调制。本版范围为导演、摄影、灯光、表演、剪辑与动作设计，声音部分不采用。

## 可激活规则

### P01 门槛把道德选择变成物理动作

- 触发：角色必须决定让谁进入、把谁隔离、是否回头或是否关门。
- 首要注意：人物分处门、玻璃、窗、闸机或狭窄通道的哪一侧。
- 动作：先建立边界和两侧利益，再让一个可见动作改变边界状态；用反应近景确认代价。
- 可见效果：抽象立场成为不可撤回的空间决定。
- 边界：如果场景没有真实通行压力，不要硬塞门或玻璃。

### P02 先给路线图，再允许混乱

- 触发：追逃、营救、群体冲撞或多障碍动作段。
- 首要注意：起点、目标、瓶颈、替代路线和威胁来向。
- 动作：用宽景或轴线镜头建立地理；冲突升级后切入手持中近景、局部身体和冲击；关键转折后回到地理镜头。
- 可见效果：观众既感到失控，又能判断行动成败。
- 边界：不要把地理镜头拍成无动机的航拍展示。

### P03 节奏来自状态切换，不来自恒定快剪

- 触发：一段戏包含危险、喘息、判断或牺牲中的两种以上状态。
- 首要注意：哪一刻信息结构或人物目标真正变化。
- 动作：威胁爆发时缩短镜头；余波与伦理争执恢复中长镜；牺牲和结尾允许长时间停留在表情、动作或空白上。
- 可见效果：速度变化本身传达威胁和情绪重量。
- 边界：纯信息段不要因“像灾难片”而无故加速。

### P04 近景只奖给决定与身体代价

- 触发：角色发现真相、压住恐惧、承担损失或改变立场。
- 首要注意：眼神、呼吸、汗血、抓握、迟疑和保护性接触。
- 动作：先让行为累积，再在选择点进入近景；以手、脸或身体负荷的细节完成情绪，而非只靠喊叫。
- 可见效果：情绪像从生存劳动中挣出来，而不是配乐强迫出来。
- 边界：不要让所有对白都采用同等强度的大特写。

### P05 群像构图显示联盟与排斥

- 触发：群体争执、恐慌扩散、甩锅或临时结盟。
- 首要注意：谁独占前景、谁被压在边缘、谁与谁共享视线或站位。
- 动作：先用群体画面显示阵营，再用选择性反应镜头指出意见传播；边界动作后重组站位。
- 可见效果：社会压力不靠解释台词也能读懂。
- 边界：人物较少或立场未分化时，不要制造虚假对立。

### P06 冷暖与明暗承担状态规则

- 触发：场景在制度空间、暂时安全、战术黑暗、露天灾后或亲密记忆之间切换。
- 首要注意：光色变化能否对应安全、权力、可见性或记忆。
- 动作：制度/运输空间以偏青灰、绿白实用光为基线；短暂亲密可用暖色；黑暗用于改变威胁感知规则；露天高潮可转为灰白高亮；极短记忆可用柔白高调形成情感断层。
- 可见效果：颜色告诉观众“规则变了”，而不是覆盖所有镜头的滤镜。
- 边界：保留肤色层次；不要全片统一青绿，也不要把暖色自动等同安全。

### P07 透视线与反射压缩封闭空间

- 触发：长廊、车厢、楼梯、隧道或重复窗口空间。
- 首要注意：轴线、消失点、层叠门框、玻璃反射和前景遮挡。
- 动作：用单点透视暴露距离与阻碍；让反射、脏玻璃或门窗造成延迟看见和多层行动；在冲突中保持主轴可追踪。
- 可见效果：狭窄空间同时拥有深度、压迫和信息悬念。
- 边界：反射不得使关键动作不可辨认。

### P08 威胁先经由反应或局部进入

- 触发：感染显现、危险逼近或角色尚未理解异常。
- 首要注意：观众比谁先知道、知道多少。
- 动作：可先给人物视线、局部肢体、玻璃后的模糊运动或他人可见反应，再完整揭示威胁；本版不补充声音线索。
- 可见效果：惊吓来自认知差，而不是随机跳吓。
- 边界：若动作目标已经公开，继续遮掩会拖慢场面。

### P09 身体异化必须遵守生物规则

- 触发：感染、抽搐、失控或非人化转变。
- 首要注意：颈、下颌、脊柱、重心、关节和呼吸的连续变化。
- 动作：给演员/动画明确动作链：疼痛阻滞 → 重心崩塌 → 关节错向 → 视线重新锁定 → 爆发移动；其他角色的退缩与冻结为其提供尺度。
- 可见效果：怪物性来自身体现象，而不只靠妆效。
- 边界：避免无规则的全身乱抖和每次同一种抽搐模板。

### P10 亲情弧线用触碰方式变化来完成

- 触发：疏离照顾者逐步承担责任，或亲密关系在灾难中重建。
- 首要注意：人物何时回避接触、何时功能性拉拽、何时主动保护或告别。
- 动作：让接触从稀少/工具化，经过救援中的负重和抓握，发展到自愿拥抱、遮挡或放手；高潮以一个简明动作结算。
- 可见效果：关系变化可在静音状态下读懂。
- 边界：若关系不是本场核心，不要强行套亲情弧。

### P11 宏观灾难与微观表情交替

- 触发：威胁规模扩大，同时个体选择仍是叙事中心。
- 首要注意：哪个宽景提供数量/路线，哪个近景提供伦理重量。
- 动作：宽景交代群体运动和空间后果，中近景追踪角色选择；每次切换必须新增尺度或意义。
- 可见效果：既有灾难规模，又不丢人物。
- 边界：不要为展示群众或特效反复切无新增信息的宽景。

### P12 以已铺垫的可见线索解除误判（视觉适配）

- 触发：幸存者被体制、武装或陌生群体误判为威胁。
- 首要注意：当前项目已铺垫的动作、物件或关系证据如何使身份被辨认。
- 动作：先维持轮廓或信息不全造成的危险判断，再通过当前项目已有的可见线索澄清身份，最后解除行动。
- 可见效果：悬念与主题在同一个动作中落地。
- 边界：信号必须由人物经历铺垫，不能临时从天而降。
- 依据范围：本版保留误判与澄清的结构，将表达限定为视觉线索；这些视觉替代是当前版本的应用转译，不等同于原片中实际采用的表达方式。

## 四维 Profile

### 导演

空间规则与伦理选择同构；灾难升级围绕瓶颈、门槛和阵营重组；高潮从“打败威胁”转向“愿意承担什么”。

### 摄影与光影

车厢式轴线、门框与玻璃分层；宽景负责地理，中近景负责身体；青灰/绿白制度基线、暖色亲密口袋、战术黑暗、灰白露天高潮与柔白记忆形成状态对照。

### 表演

日常段克制，靠视线和手部；危机段强调呼吸、负重、保护性触碰；感染表演是分阶段的身体规则；情绪爆发必须有先前动作积累。

### 剪辑

快慢有波形：突袭加速、余波放松、伦理争执停留、牺牲延长；反应镜头与局部揭示控制认知差；动作转折后重新确认空间。
