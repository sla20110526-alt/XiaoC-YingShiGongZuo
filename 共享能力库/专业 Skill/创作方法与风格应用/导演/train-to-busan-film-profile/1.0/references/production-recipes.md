# 生产食谱

所有模式都按调用入口提供的当前工作环节、原执行单元和既定格式交付。仅填写本次相关字段，并引用已确认的项目依据。

## PLAN｜方案

先按需要写场景卡；只填写当前任务存在的字段：

1. 空间容器与唯一主轴；
2. 起点、目标、瓶颈、替代路线；
3. 威胁如何感知或失去感知；
4. 群体分成哪些利益阵营；
5. 主角必须承担的不可逆代价。

按 [规则选择器](decision-qa.md#规则选择器) 选择最小充分规则集。没有群体，不调用群像规则；没有关系弧，不调用亲密触碰规则；没有叙事状态变化，不加入色彩规则。

## MAKE｜镜头与画面表达交接

向原执行单元提供本次相关内容：`原有镜号或任务引用 / 节拍或时长 / 画面与机位 / 走位或屏幕方向 / 光色状态 / 剪辑目的 / 激活规则`。正式字段和成果写入沿用原执行单元的既定约定。用户要求摄影技术规格时，再提供本次范围内的焦段、镜头高度等建议。

在镜头创作环节，可以按下列关系组织动作段建议；在 Prompt 装配环节，按已确认分镜转译，不新增或重排镜头：

1. 建立空间：一条主轴、威胁入口、角色目标。
2. 第一次侵入：用反应、局部或玻璃后的运动改变认知。
3. 身体碰撞：中近景、手持或遮挡提高临场性，但保留动作方向。
4. 决定点：门槛动作或保护性接触改变关系。
5. 地理复位：短宽景确认谁到达、谁被留在另一侧。
6. 余波：延长一个镜头，让呼吸、目光或身体重量承担情绪。

向 Prompt 执行环节提供画面表达时，准确承接已确认的空间结构、人物站位、威胁方向、主光来源、动作时刻和镜头目的。目标模型、模式、参考素材与正式 Prompt 模板均继承项目选择；影响装配的缺口返回原入口。模型适配按该入口已有方式完成。

## REWORK｜局部改稿

针对当前任务诊断，并向原执行单元提供局部修改建议：

- 看不懂：补一枚建立路线的镜头，或删掉破坏轴线的切换。
- 不紧张：建立可验证的威胁规则和倒计时边界，而非单纯加抖动。
- 不感人：把解释台词换成承重、抓握、挡住、迟疑或放手等行为。
- 群像扁平：用站位和反应传播重组阵营，不给每个人平均对白。
- 影调单一：让色温/亮度只在状态改变时转折，保留中性过渡。
- 剪辑疲劳：在突袭后增加地理复位与余波停留。

优先指出决定性位置。已锁定内容需要调整时，明确列出调整建议及原因，交由原执行单元按既定流程处理。

## CHECK｜执行 QA

按 [QA 与返工路径](decision-qa.md#qa-与返工路径) 对当前适用项给出依据、问题和修复建议，交回原执行单元。若没有实际成片，只报告可检查的方案内容。
