# 《沙丘2》导演风格

## 目标

把场景的剧情功能转成可拍摄的空间、权力、群体、节奏和后果设计。保留用户的题材、人物与情节，只复用组织方法；不得复制影片角色、台词、服装、情节或具体镜头。

## 使用资料

- 生成或评审导演方案前，读取 [references/profile.md](references/profile.md)。
- 当用户要求证据、精确复刻、技术参数或质疑置信度时，再读取 [references/evidence-boundaries.md](references/evidence-boundaries.md)。

## 工作方法

1. 从用户材料中提取场景功能、场前／场后权力、空间压力、群体立场、关系转折和爆发等级。缺失项可合理推断，但要把影响结果的假设说清楚。
2. 选择一个主模式：仪式／政治、亲密／信任、战术／动作、幻视／阈值。最多再选一个辅助模式；不要堆叠全部特征。
3. 先设计空间和权力，再设计表演与镜头。用“建立秩序—积累压力—短促爆发—停留后果”组织节奏，但没有爆发需求的场景可以停在压力或选择。
4. 群体必须有统一任务、视线目标和变化波次；群众不是随机背景。
5. 动作段落先交代目标、障碍、方向和退路，再进入功能细节；结束必须回到身体、关系或政治后果。
6. 用 Profile 的禁用条件和自检清单做最后检查。

## 输出要求

按任务需要输出以下最小集合：

- 场景主模式与一句导演命题。
- 空间压力、权力中心及其变化。
- 8–20 个导演节拍或相称的短方案，不机械扩写。
- 主体调度、群体调度、关键沉默点和唯一主要爆发。
- 必拍的空间、关系、动作因果与后果。
- 交给摄影、光影和表演的边界清楚的约束。
- 3–6 条针对当前场景的禁用项与自检结论。

## 多 Skill 协作

若同时调用四个风格 Skill：导演 Skill 先确定为什么看、空间与节拍；表演 Skill 定义人物如何行动；摄影 Skill 决定从哪里看；光影 Skill 决定什么被看见。避免四份方案重复改写同一职责。

## 关键边界

- “慢、宏大、黑暗、暖色”本身不是导演风格，必须对应权力、人物或因果。
- 不为追求风格改变用户已确定的剧情目的。
- 不把自动镜头统计当作逐镜头复刻标准。
- 用户未要求完整方案时，给出可执行的最小结果，不强行套固定篇幅。
