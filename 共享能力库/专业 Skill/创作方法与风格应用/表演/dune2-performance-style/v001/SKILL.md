# 《沙丘2》表演风格

## 目标

把人物目标与关系转成可排练的身体行动、视线、距离、停顿和幅度变化。保持内在压力大于外在动作；不复制原片角色，也不把克制误写成统一低沉或面无表情。

## 使用资料

- 生成或评审表演方案前，读取 [references/profile.md](references/profile.md)。
- 当用户要求声音表演、逐句台词节拍、证据或精确复刻时，再读取 [references/evidence-boundaries.md](references/evidence-boundaries.md)。

## 工作方法

1. 为每个主要人物确定角色功能、公开目标、真实目标、基础身体状态、关系距离和幅度峰值。
2. 每个节拍使用一个行动动词和一个主要外部动作；动作必须改变信息、距离或权力，避免持续微表情填充。
3. 先听后反应，允许判断在对方说完后形成。权力上升通常表现为动作减少、站位稳定和别人先移动。
4. 亲密戏使用具体任务与距离；公共场景让核心人物低幅度、群体中高幅度；动作戏保持功能性和伤痛连续；对峙只允许一次短爆发。
5. 高幅度表演之后必须安排身体、关系或群体后果。
6. 若用户没有提供声音或对白材料，不把语速、音高、口音和逐句重音写成强制规则；列为待补听问题。

## 输出要求

按任务需要输出以下最小集合：

- 人物功能与一句表演命题。
- 公开目标、真实目标和唯一泄露动作。
- 基础身体状态：重心、呼吸、视线与动作速度。
- 节拍级行动动词、距离／触碰变化和幅度 0–3。
- 唯一主要爆发及其身体／关系后果。
- 群体中的中心、见证、抵抗与同步波次。
- 待补听的声音问题、禁用项与排练自检。

## 多 Skill 协作

若同时调用四个风格 Skill，接受导演的场景目的和调度边界，在摄影定镜前给出身体行动、距离和视线需求；不替导演改变情节，不替摄影规定无关的景别。

## 关键边界

- 少做不等于不做；眼睛、呼吸、重心或任务中必须有可读变化。
- 信仰者不能演成笑料，威胁者不能演成脸谱怪物。
- 不让所有角色共享同一种低沉、迟缓、紧绷状态。
- 视觉表演证据较强，声音表演仍需用户材料或补听验证。
