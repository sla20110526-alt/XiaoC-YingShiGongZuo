# 《沙丘2》摄影风格

## 目标

把场景关系转成景别、机位、构图、景深、运动和空间连续性。复用视觉关系而非复制具体镜头、器材、焦段、角色造型或场景美术。

## 使用资料

- 生成或评审摄影方案前，读取 [references/profile.md](references/profile.md)。
- 当用户要求证据、真实焦段、器材、精确复刻或置信度时，再读取 [references/evidence-boundaries.md](references/evidence-boundaries.md)。

## 工作方法

1. 确认场景模式、权力几何、人物／环境／巨物的尺度关系、相机能量和可见性优先级。
2. 先设计一个尺度镜头和一个权力镜头，再补关系镜头、功能细节与后果镜头。
3. 仪式与制度优先中心轴、阵列和静态；脆弱与未知优先有方向的负空间；亲密关系优先共享画面、侧面或肩后；动作优先地理和因果。
4. 相机默认静止或克制。每次移动必须对应目标发现、危险逼近、空间穿越、权力位移或关系破裂。
5. 快速动作中维持轴线、进入方向和目标方向，并定期回到可定位画面。
6. 不编造未由材料支持的镜头毫米数、摄影机、滤镜或运镜设备；可给视觉意图和可替代范围。

## 输出要求

按任务需要输出以下最小集合：

- 主摄影模式与一句视觉命题。
- 尺度参照、构图轴线、机位高度和景深意图。
- 镜头组：尺度—关系—功能细节—后果。
- 每次运镜的启动理由、停止点和空间方向。
- 动作场景的轴线、目标方向和回到地理宽景的位置。
- 前景遮挡与画中框的叙事功能。
- 给光影 Skill 的可见性优先级，以及当前场景禁用项。

## 多 Skill 协作

若同时调用四个风格 Skill，先接受导演 Skill 的场景功能和调度、表演 Skill 的身体行动与距离，再把它们转成镜头；不要替灯光规定精确曝光，也不要替导演改变剧情节拍。

## 关键边界

- 2.39:1 是参考画幅关系，不是强制交付规格。
- 居中、负空间、浅景深和大远景必须服务权力或因果，不能当装饰。
- 不用无人机式大全景替代人物尺度，不用手持摇晃替代危险。
- 用户未给场地或调度时可提出假设，但必须保留可替换性。
