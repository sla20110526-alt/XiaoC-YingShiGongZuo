# 《沙丘2》风格 Profile：证据审计与适用边界

版本：`v001`

状态：正式 Skill v001 的证据记录／边界持续有效

## 1. 已检查材料

资料包：本地《沙丘2》（2024）影片分析资料包，原片、抽帧和复核媒体未纳入版本控制。

- 全片时间轴接触表：20 页，已逐页检查。
- 分类接触表：暗调、明亮、偏冷、偏暖、长镜头候选，已做人工抽查与交叉核验。
- `frames.csv`：320 条代表帧，含时间码、亮度／色温自动标签和 100 张高质量帧索引。
- `clips.csv`：16 个复核片段，已检查全部片段的连续接触表。
- `shots.csv`：1262 个自动检测镜头，用于方向性的节奏统计。
- 高质量原帧：检查了早中后段的代表帧，重点核对暗部、浅景深、单色段和高亮沙漠。
- 原资料包覆盖不足处：额外从原片生成 8 个一分钟低分辨率连续接触表，时间为 01:30、01:40、01:49、02:01、02:10、02:20、02:28、02:33；只用于分析，没有修改原片或资料包。

## 2. 自动数据中的已知问题

### 2.1 代表帧覆盖不均

320 张代表帧明显偏向前半部：

- 00–75 分钟：276 张。
- 75–90 分钟：17 张。
- 90–105 分钟：0 张。
- 105–150 分钟：14 张。
- 150 分钟以后：17 张，其中多张是片尾字幕。

最大无代表帧间隔约 18 分 55 秒（01:27:16–01:46:11）。因此不能只用 `frames.csv` 判断全片导演与表演风格。

### 2.2 复核片段偏向前半部

16 个片段中，13 个位于前 55 分钟；后段只有 01:52、02:14、02:37 三处。后半程的连续场戏由 8 个补充样本弥补，但仍不是逐场完整观看。

### 2.3 “长镜头”自动标签不可直接采用

自动检测出现 217 秒、118 秒、91 秒和片尾 487 秒等合并段，说明同色调、渐变或运动较弱的切镜存在漏检。`shots.csv` 的中位数与快速段落可以作为节奏方向证据，但单个超长时长不能视作真实镜头长度。

### 2.4 HDR 与色彩边界

原片是 2160p、10-bit、BT.2020、PQ、Dolby Vision／HDR10 兼容源。资料包画面经过 SDR 可视化转换：

- 可以判断明暗结构、色彩角色、轮廓、光源方向和环境对比。
- 不可据此还原母版亮度、峰值尼特、精确曝光、Dolby Vision 动态元数据或最终 LUT。
- 某些暗部帧在 SDR 转换后接近全黑，因此本 Profile 不规定绝对曝光值，只规定可见性层级。

### 2.5 表演与声音边界

原片内嵌字幕为 PGS 位图，资料包没有可检索对白文本；本轮也没有完整听审声音。因此：

- 肢体、视线、表情幅度、走位、停顿和群体关系：可用。
- 语速、音高、重音、口音、呼吸声和台词节拍：待补听验证。

## 3. 节奏统计（方向性）

- 自动镜头总数：1262。
- 全片镜头时长中位数：约 3.25 秒。
- 35–40 分钟动作段：5 分钟内约 113 个检测镜头，中位数约 1.63 秒，是最密集的段落。
- 75–80 分钟与 85–90 分钟：镜头密度再次显著提高。
- 120–135 分钟：中位数约 4.38 秒，更强调集会、权力与仪式的停留。

这些数值支持“静态秩序—局部爆发—后果停留”的节奏结论，但不用于逐镜头复刻。

## 4. 置信度

| Profile | 置信度 | 可以稳定复用 | 仍需补证 |
|---|---|---|---|
| 导演 | 中高 | 场面调度、群体层级、动作结构、节奏对比 | 声音叙事、完整对白节奏 |
| 摄影 | 高 | 构图、尺度、机位倾向、景深关系、视觉地理 | 具体焦段、器材、实际运镜速度 |

| 表演 | 中 | 表情幅度、身体状态、视线、人物间距离 | 语音、口音、重音、逐句节拍 |

## 6. 使用结论

四份 Profile 已收敛为正式 Skill v001，可用于原创项目的测试场景和方案生成。它们复用组织方法，不授权逐镜、角色、台词、情节或美术元素复刻。具体项目采用前仍应由导演、摄影、灯光和表演责任人确认；声音表演结论在完成专项听审前维持较低置信度。
