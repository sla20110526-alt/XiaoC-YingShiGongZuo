# 《沙丘2》摄影风格 Profile

Profile ID：`PRF-DUNE2-CIN@v001`

状态：源 Profile 已冻结／已生成正式 Skill v001

置信度：高（构图与空间）；中（具体焦段与实际运镜参数）

## 1. 核心定义

摄影的第一任务是把**人物、地貌、建筑和权力放在同一尺度系统中**。宽景制造不可抗拒的世界，近景则把表情压缩成少量可读信号。镜头运动克制、有重量，只在人物、危险或权力发生位移时启动。

原片画幅约为 2.39:1。Profile 复用其横向秩序和尺度关系，不要求复制具体摄影机、镜头品牌或焦段。

## 2. 构图语法

### 2.1 权力中心：正面、对称、几何化

- 仪式和政治场景优先使用中心轴、台阶、环形、门洞和重复列阵。
- 掌权者可以靠近中心且保持静止；被观察者常被门框、前景或人群夹住。
- 对称不应覆盖全片，只在制度、仪式或命运压过个人时使用。

### 2.2 脆弱状态：负空间与偏置

- 人物面对未知、等待或被抛弃时，放在画面边缘或下方，给天空、沙丘、墙面留出主导面积。
- 负空间必须有方向：威胁将进入、人物将离开、视线指向或权力中心缺席。
- 不用“空”装饰画面；空必须构成叙事压力。

### 2.3 巨物尺度：让人物成为计量单位

- 环境宽景保留清晰的人体、队伍、交通工具或建筑入口作为尺度参照。
- 巨物不必总拍完整；可用局部遮天、低机位边缘和人物反应建立体量。
- 大场面中至少有一镜同时容纳人物与巨物，避免只靠分切宣称“巨大”。

### 2.4 前景遮挡与画中框

- 使用肩、头、岩壁、门洞、仪器、织物和建筑边缘制造被观察感。
- 前景可以失焦并占据较大面积，但必须指向视线关系或空间层级。
- 对话中不追求干净覆盖；允许人物被同伴和空间部分遮住。

## 3. 景别与景深

- 环境：宽幅大景别，地平线与建筑轴线清楚，人物较小。
- 权力近景：正面或轻微三分之四，背景压平，面部动作极少。
- 亲密近景：侧面、肩后、共享画面；浅景深把环境化为色块，但保留对方的轮廓或前景。
- 功能细节：手、刀、呼吸装置、药剂、眼睛、沙粒和机械接口；每个细节必须改变下一步行动。
- 不绑定具体毫米数。视觉上采用“宽广环境 + 浅景深近景”的强反差，避免中景平均化整场。

## 4. 机位与运动

### 4.1 静态是默认，运动是事件

- 仪式、权力和凝视场景以静态或几乎不可察觉的缓慢移动为主。
- 相机启动必须对应：人物进入权力、目标被发现、危险逼近、空间被穿越或关系破裂。
- 停机同样重要：人物完成选择后，让画面落定。

### 4.2 机位高度表达关系

- 低机位：巨物、战术障碍、威胁身体和人物被地形压迫。
- 平视近景：亲密、判断与道德冲突。
- 高位／俯视：仪式图案、群众秩序、孤立人物或命运尺度。
- 不把低机位等同于“英雄”；同一机位也可让人物显得渺小。

### 4.3 动作摄影保持地理

- 先给宽镜确立轴线，再进入快速细节。
- 短切中维持人物、目标和来袭方向的一致。
- 运动模糊、尘沙和遮挡可以增加危险，但每 3–6 个紧镜后应回到一个可定位画面。
- 冲击时允许突然近、突然低或突然静止；避免无意义摇晃。

## 5. 四种摄影模式

### A. 沙漠／巨物模式

- 横向线条、低／高地平线、人物剪影、尘沙分层。
- 画面保留大面积近白或暖灰背景，黑色人体成为标尺。
- 证据：00:38、00:50–00:57、02:14、02:36 附近。

### B. 洞穴／亲密模式

- 浅景深近景、前景遮挡、侧面轮廓、低照度背景。
- 两人关系优先共享画面；单人近景只用于关系发生变化的节点。
- 证据：00:28–00:34、00:40–00:45、01:49、02:33 附近。

### C. 仪式／权力模式

- 中心轴、重复阵列、台阶、环形结构、俯视图案。
- 宽景说明秩序，微距说明仪式的物质性；两者之间避免大量普通中景。
- 证据：00:19–00:26、01:40、02:01、02:20、02:28 附近。

### D. 异域规则模式

- 允许近单色、极端高反差、正面肖像和抽象尺度，但必须与特定地点或感知规则绑定。
- 证据：00:06–00:08 的日蚀橙；01:11–01:17 的黑太阳单色；01:52 的蓝色主观段。

## 6. 可执行摄影规则

### 必须

- 每场先写一个“尺度镜头”和一个“权力镜头”。
- 宽景中提供人体或物体标尺。
- 对话设计景别时，先判断人物是否共享空间，再决定是否拆为正反打。
- 动作场景标注轴线、进入方向、目标方向和安全区。
- 每个微距插入都必须触发行为、信息或情绪变化。

### 可以

- 让人物被前景遮住 20%–60%，强化观察与压迫。
- 用接近抽象的局部建立巨物，再用含人物的宽景校准尺度。
- 在亲密场景中让焦点停留于倾听者，而不是自动跟随说话者。

### 禁止

- 无叙事原因的持续漂移、环绕和手持摇晃。
- 所有角色都用同一种居中英雄近景。
- 用极广角贴脸制造廉价夸张。
- 大场面只拍无人机式大全景，缺少人物尺度与行动因果。
- 为了“电影感”滥用炫光、浅景深或黑边。
- 复制角色造型和具体镜头；只复用空间与视觉关系。

## 7. 生成摄影方案时的输入／输出

### 输入字段

- `scene_mode`：沙漠／洞穴／仪式／异域规则／混合。
- `power_geometry`：中心／边缘／对峙／包围／缺席。
- `scale_relation`：人物主导／环境主导／巨物主导。
- `camera_energy`：静止／缓慢／战术移动／爆发。
- `visibility_priority`：脸／身体／工具／地理／群众。

### 输出字段

- 景别、机位高度、构图轴线和运动理由。
- “尺度镜头—关系镜头—功能细节—后果镜头”的镜头组。
- 景深意图与前景遮挡设计。
- 动作轴线和每次回到地理宽景的位置。
- 交给灯光 Profile 的可见性优先级。

## 8. 自检清单

- 画面里是否存在可读的尺度参照？
- 居中／对称是否真的对应权力，而非习惯？
- 相机为什么在此刻移动？
- 快速段落中，观众是否仍知道目标和危险方向？
- 近景是否记录了人物变化，而非只是覆盖对白？
- 前景遮挡是否服务视线和层级？
