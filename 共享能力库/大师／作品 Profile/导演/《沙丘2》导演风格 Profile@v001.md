# 《沙丘2》导演风格 Profile

Profile ID：`PRF-DUNE2-DIR@v001`

状态：源 Profile 已冻结／已生成正式 Skill v001

置信度：中高

## 1. 核心定义

用**空间尺度与群体秩序先定义权力，再用克制的人物行为改变权力**。场面不是为了展示世界观，而是让观众感到人物被地貌、建筑、信仰和政治结构包围。叙事节奏遵循“建立秩序—积累压力—短促爆发—停留后果”。

## 2. 核心导演语法

### 2.1 先让空间说话

- 新场景先交代地形、入口、出口、垂直层级和人群分布。
- 人物进入画面后，空间仍保持主导；主角不必立即占满画面。
- 巨大空间与小人物的比例必须对应剧情压力，而不是单纯做奇观。
- 当人物真正取得权力时，再允许他站到几何中心、停止移动并让群体围绕他重排。

### 2.2 群体是“合唱队”，不是背景群众

- 群体统一朝向、跪伏、退让、分裂或沉默，直接表达权力变化。
- 关键人物的权威来自“别人如何看他、给他让出多少空间”，不只来自台词。
- 群体动作先形成整体图案，再选择少数个体反应；不要随机铺满群众特写。

### 2.3 克制铺垫，极端事件

- 常态场景保持低幅度动作、简洁对白覆盖和明确停顿。
- 爆发点可以极短、极响、极亮或极暴力，但必须由前面的静态秩序蓄力。
- 爆发后保留伤者、灰尘、沉默、视线或关系变化；不要立刻跳到下一场奇观。

### 2.4 亲密关系用距离变化，而不是解释

- 优先使用并肩、近距离侧面、肩后和共享画面的双人关系。
- 情绪转折由靠近、撤开、避开视线、触碰失败、延迟回应来完成。
- 每场亲密戏只选一个主要身体事件，例如包扎、递物、拥抱、分开或共同观察。

### 2.5 动作先清楚，再猛烈

动作段落按以下顺序组织：

1. 建立目标、障碍、危险方向和退路。
2. 用一个宏观画面说明人物与巨物／地貌的尺度。
3. 进入武器、手、脚、装置和呼吸等功能性细节。
4. 在爆发中保持屏幕方向和因果连续。
5. 回到后果与关系，不以“更大的爆炸”代替结束。

35–40 分钟的自动统计中位镜头约 1.63 秒，说明快速剪辑用于局部高压；全片中位数约 3.25 秒，快速节奏不是常态。

### 2.6 主观状态必须稀缺

- 幻视、药物、预言或极端环境可以改变色彩、时间和空间连续性。
- 每次主观突破只保留一个清晰感知规则，例如蓝色漂移、眼睛微距、时间跳切或声画断裂。
- 回到现实后恢复稳定空间，避免全片都处在“梦境滤镜”。

## 3. 四种场景模式

### A. 仪式／政治模式

- 主画面：正面、中心、对称、纵深或俯视。
- 调度：领袖少动，群体先动；层级通过台阶、环形结构和空场表现。
- 节奏：宽景停留，细节只服务仪式动作或权力转移。
- 证据：01:40、02:01、02:20、02:28 附近。

### B. 亲密／信任模式

- 主画面：双人近景、侧面或肩后，背景简化。
- 调度：人物共享同一物件或同一任务，情绪通过距离与视线变化。
- 节奏：允许沉默和未完成动作；不为每句台词切反应。
- 证据：00:33、00:43、01:49、02:33 附近。

### C. 战术／动作模式

- 主画面：先宽后紧；先目标后撞击。
- 调度：动作由地形和工具驱动，人物必须解决具体空间问题。
- 节奏：短切集中于操作与危险，段落头尾保持较长空间镜头。
- 证据：00:06、00:38、00:54、01:30、02:10、02:14 附近。

### D. 幻视／阈值模式

- 主画面：微距、局部、反射、漂白或有限色彩突破。
- 调度：身体先失衡，意识画面后出现；不要先解释再幻视。
- 节奏：短促、非连续，随后明确回到现实后果。
- 证据：00:25、01:52 附近。

## 4. 可执行导演规则

### 必须

- 每场写明：空间压力、权力中心、群体方向、人物关系变化、爆发点与后果。
- 场景开始的前 3–5 个镜头中完成空间和权力关系建立。
- 每场只设置一个主要视觉命题和一个主要表演转折。
- 动作场景必须在剪辑前画出屏幕方向与地理图。
- 群体场景必须给群众统一任务、节奏和视线目标。

### 可以

- 用硬切把亲密状态撞向外部暴力，形成命运压力。
- 用建筑孔洞、门、岩缝和遮挡把人物变成被观察对象。
- 在权力完成转移时，减少主角动作、增加他周围人的动作。

### 禁止

- 把“慢”理解为没有戏剧动作的空镜堆积。
- 全程快速剪辑、全程手持或全程宏大宽景。
- 每句台词都给正反打与反应镜头。
- 用现代轻佻语气消解信仰、危险和死亡后果。
- 把群众当随机摆动的背景，或用掌声／喊叫代替明确立场。
- 复制具体角色、服装、台词和情节；Profile 只复用组织方法。

## 5. 生成场景方案时的输入／输出

### 输入字段

- `scene_function`：仪式／亲密／战术／幻视／过渡。
- `power_before` 与 `power_after`：场前、场后权力归属。
- `space_pressure`：开阔压迫／封闭压迫／安全／不稳定。
- `crowd_role`：见证／服从／怀疑／分裂／敌对。
- `emotional_turn`：人物关系的唯一主转折。
- `eruption_level`：0–3，是否存在短促爆发。

### 输出字段

- 场面调度图与人物移动顺序。
- 8–20 个导演节拍，而非逐句镜头列表。
- 必拍空间镜头、关系镜头、动作因果和后果镜头。
- 演员任务、群体任务与沉默点。
- 应交给摄影、灯光和表演 Profile 的明确约束。

## 6. 自检清单

- 去掉美术和色彩后，这场的权力关系仍清楚吗？
- 主角的权力变化是否体现在别人和空间的变化上？
- 动作前是否知道危险来自哪里？
- 爆发后是否留下可感知的后果？
- 是否把一个本应由动作完成的转折写成了解释性台词？
- 特殊视觉状态是否真正稀缺？
