# 《沙丘2》光影风格 Profile

Profile ID：`PRF-DUNE2-LGT@v001`

状态：源 Profile 已冻结／已生成正式 Skill v001

置信度：中高（明暗关系与色彩角色）；中低（精确曝光、HDR 与 LUT）

## 1. 核心定义

以**可信光源造成雕塑性明暗**：光通常来自太阳、天空、门洞、顶孔、窄缝、火焰或明确的仪式光区。人物不必被完整照亮，但眼睛、轮廓、手势或道具中至少有一个叙事锚点可读。色彩不是统一滤镜，而是不同世界规则和意识状态的语法。

本 Profile 基于 SDR 可视化资料，规定的是光影层级与色彩功能，不规定母版峰值、尼特值或最终 LUT。

## 2. 总体光影语法

### 2.1 大光源，少补光

- 优先单一主方向或一个占主导的大环境光源。
- 阴影允许深，面部允许低于环境；避免为“看清演员”平均抬亮所有方向。
- 补光只用于保留叙事锚点，不用于消除阴影。
- 负补光和遮挡比额外灯具更重要。

### 2.2 光必须落在空间结构上

- 门洞、岩缝、圆孔、台阶和顶孔形成大块光区。
- 让人物进入、离开或穿越光区，从而把权力和选择变成可见动作。
- 光束与烟尘只在有明确开口和空气介质时出现。

### 2.3 人脸不追求均匀漂亮

- 权力人物常由窄侧光、顶光或背景轮廓塑形，正面保持克制。
- 亲密场景保留一侧眼睛、鼻梁、嘴角或皮肤轮廓，不必同时照亮双眼。
- 群体场景优先让领袖或仪式中心可读，其他人形成层级化暗部。

### 2.4 高亮不是清洁，暗部不是模糊

- 高亮沙漠使用近白天空、暖灰／淡赭地表和黑色剪影，靠尘沙保留层次。
- 暗场使用光池、边缘和局部材质，而不是整体压黑。
- 每个画面应有一个最亮叙事区域和一个最深压迫区域。

## 3. 色彩角色

### 3.1 常态色：沙、石、皮肤、黑

- 主体为低至中饱和的沙色、暖灰、棕、石色和黑。
- 暖色来自环境与光源逻辑，不使用统一橙色滤镜。
- 皮肤可偏暖，但避免“健康广告感”；灰尘与汗水属于环境质感。

### 3.2 日蚀橙：战术异常与环境敌意

- 00:06–00:08 的深橙／黑是特殊天象或感知规则，不是普通日落。
- 允许极端剪影、有限中间调和被环境吞没的面孔。
- 只能用于明确异常环境；常规沙漠场景禁止套用。

### 3.3 黑太阳单色：异域制度与身体威胁

- 01:11–01:17 使用近黑白、高亮皮肤、黑色服装和硬质结构。
- 单色必须绑定地点规则；进入和离开该空间时恢复常态色彩。
- 不把“去饱和”当通用高级感。

### 3.4 稀缺蓝：药物、预言、意识阈值

- 蓝色只在液体、眼睛、幻视或极少量冷光中出现。
- 冷色的价值来自稀少；全片普遍使用蓝橙对比会破坏语法。
- 01:52 附近允许漂白高光和蓝色侵入画面，随后回到常态。

## 4. 五种光影模式

### A. 高亮沙漠

- 主源：大面积日光／天空光。
- 关系：背景接近高亮，人物与设备形成中暗轮廓。
- 空气：尘沙、热浪、烟和距离衰减提供层次。
- 目标：不是“曝得漂亮”，而是让环境显得无处可逃。
- 证据：00:50–00:57、02:10、02:14、02:36 附近。

### B. 洞穴／室内亲密

- 主源：侧面门洞、低位反射或局部暖光。
- 关系：背景深暗，脸部只保留一个可读锚点。
- 目标：把人物从公共身份缩小到呼吸、眼神和触碰。
- 证据：00:17–00:22、00:40–00:45、01:49、02:33 附近。

### C. 仪式／群众

- 主源：顶部窄束、圆孔、台阶光带或中心光池。
- 关系：领袖／祭品／动作中心亮，群体形成暗色海面。
- 目标：光先组织群众图案，再照亮个体。
- 证据：00:24–00:26、01:40、02:01、02:20 附近。

### D. 暖暗权力空间

- 主源：高位或侧后硬暖光，保持深黑背景。
- 关系：皮肤和金属边缘被切出，正面不过度补亮。
- 目标：用低暖光制造制度、暴力和不可逆选择，不制造舒适感。
- 证据：02:20–02:34 附近。

### E. 主观／幻视

- 主源：蓝色侵入、漂白高光、局部过曝或方向不稳定的光。
- 关系：牺牲正常肤色与空间连续，但保留眼睛、液体或身体反应作为锚点。
- 目标：明确人物跨过意识阈值。
- 证据：00:25–00:26、01:52 附近。

## 5. 可执行灯光规则

### 必须

- 每场写明唯一主光源、最亮叙事区、最深压迫区和必须可读的锚点。
- 先用空间开口和遮挡设计光，再考虑补灯。
- 群体场景建立三级可见性：中心人物、关键见证者、群众整体。
- 亲密场景只保证与转折相关的一只眼、一个轮廓或一双手可读。
- 特殊色彩必须在场景设定中有明确原因和退出条件。

### 可以

- 让局部黑位失去细节，只要叙事锚点仍在。
- 让高亮背景接近漂白，用人物剪影和空气保持空间。
- 在一个场景中让人物跨过光区，直接表现立场改变。
- 使用实景尘、雾、烟建立体积光，但浓度服从空间可读性。

### 禁止

- 均匀三点布光、双眼恒亮、全员美容式面光。
- 用统一橙色 LUT 代替环境暖色。
- 滥用蓝橙互补、霓虹边光或无来源 RGB 色光。
- 暗场整体压黑到关键动作、眼神和道具不可辨。
- 高亮场景把所有层次推成纯白，失去轮廓和空气距离。
- 把日蚀橙、黑太阳单色和蓝色幻视混在同一常态场景。

## 6. 生成灯光方案时的输入／输出

### 输入字段

- `environment_mode`：高亮沙漠／洞穴亲密／仪式／暖暗权力／幻视。
- `motivated_source`：太阳／天空／门洞／顶孔／火／实用灯／未知主观源。
- `visibility_anchor`：眼／脸侧／手／道具／轮廓／群众中心。
- `power_target`：谁被光确认，谁被暗部吞没。
- `color_exception`：无／日蚀橙／黑太阳单色／稀缺蓝。

### 输出字段

- 主光方向、光区形状、遮挡与负补光设计。
- 三级可见性层级和不可丢失的叙事锚点。
- 背景、肤色、服装和空气介质的相对关系。
- 特殊色彩的触发、持续和退出规则。
- SDR 预览与 HDR 母版分别需要验证的项目。

## 7. 自检清单

- 关掉所有补光后，主光逻辑是否仍成立？
- 最亮区域是否真的是叙事重点？
- 暗部是否保留了至少一个行为锚点？
- 色彩变化是否对应世界规则或意识变化？
- 高亮背景里是否仍有尺度和空气层次？
- 这场是否误用了只应出现一次的特殊色彩？
