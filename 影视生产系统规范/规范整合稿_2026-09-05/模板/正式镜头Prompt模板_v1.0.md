# 小虫的影视生产流｜正式镜头 Prompt 模板 v1.0

状态：v1.0正式冻结版，用户于2026-09-05确认重新冻结。采用于[视频生成综合执行](../视频生成综合执行/执行流程.md)。来源模板保留在旧项目，仅用于历史追溯；本模板不依赖旧项目阶段或旧Skill。

用途：根据用户确认的目标模型，交付可整体复制进对应全能参考模式对话框的正式分镜 Prompt。

## 0. 装配前确认

正式分镜Prompt装配继承分镜阶段或当前任务已确认的目标模型及模式；仅缺少明确依据时询问。以下为本系统当前规范采用的时长基线，并非本次对外部模型产品参数的重新核验：

- Seedance 2.0 全能参考模式：单条视频最长 15 秒。
- Seedance 2.5 全能参考模式：单条视频最长 30 秒。
- MiniMax H3 全能参考模式：单条视频最长 15 秒。

未确认目标模型时，不装配正式分镜 Prompt。画幅和分辨率由用户在生成平台选择，不写入正式分镜 Prompt。

固定要求：

1. 正式 Prompt 只使用“连续单镜头”或“镜头组”两种格式。
2. `画面质感`填入当前有效项目风格与分镜依据中的实际短执行描述，不写读取指令、阶段名称或管理语言。
3. 资产参考只列本次生成实际锚定并调用的资产；未调用的人物、场景、道具、声音或外部参考行整行删除。
4. 当前任务已确认并实际采用的声音资产，按真实平台引用与文件对应关系加入；尾帧、视频和额外音频参考只在用户明确提供时加入`资产参考`。
5. 镜头正文直接使用资产参考中等号左侧的使用名，不重复书写`使用名=@资产名`。
6. 镜头结尾状态写在对应镜头正文内，不单设字段。
7. 连续单镜头和镜头组总时长与当前工具端选择一致；镜头组各镜头时长之和必须等于镜头组总时长。
8. 分析、检查、生成记录和返工理由均放在正式 Prompt 代码块外。
9. 同类型多个资产按示例逐行增加，每个资产使用独立使用名，不得把多个人物、场景或道具合并成一行。
10. 装配前依据当前模型及模式的有效参数核对实际参考负载；超限或必要限制依据不明时，在代码块外说明受影响生成单元、引用及待决定事项，不自行拆分、删镜、压缩时长或切换模型。
11. 每个镜头的景别必须带明确对象，例如场景远景、角色名近景、双人中景或道具特写，不单独写无对象的“近景 / 中景”。
12. 每个镜头按已确认分镜写清开始状态、主体动作和稳定结束状态；相邻镜头的景别对象、景别、机位角度和构图继承有效设计，发现需重新设计的重复或衔接问题时在代码块外提出，不以模板为由改镜。
13. 镜头组第一镜按已确认设计承接上一组尾镜的动作、视线、信息或声音落点；景别、机位和构图差异以当前有效分镜为准，不在装配时另作创作决定。
14. 正式分镜 Prompt 必须针对用户确认的目标模型调整表达重点和指令组织，不得用同一套措辞机械套用全部模型。
15. 每个连续单镜头或镜头组的总时长不得超过目标模型单条视频最长生成时长；超过时停止装配，指出对应生成单元并等待用户决定调整分镜或改用其他模型，不得擅自压缩、删镜或修改镜头时长。
16. 分镜及正式分镜 Prompt 中的镜头时长只允许以 0.5 秒为最小单位，不使用帧数或 0.1 秒级时间值。
17. 画幅和分辨率属于生成平台设置，不写入正式分镜 Prompt。
18. 下方光线规则、字幕限制和音乐限制是固定生成约束，每个连续单镜头及每个镜头组的完整 Prompt 中均须保留。字幕与音乐由后期合成。
19. 画面与动作描述只写可见内容，声音描述只写可听内容；资产引用、摄影指令及固定生成限制按模板保留。

## 1. 连续单镜头 Prompt

资产行中的`@资产名`是结构占位，交付时必须替换为实际平台引用名，并与真实文件核对，见[资产身份与引用约定](../通用约定/资产身份与引用.md)。本文省略号均须用已确认内容替换；缺少必需设计或引用时返回具体缺口，不能把占位符当作可执行交付。

焦段采用已确认数值或明确表达；原台词逐字保留并在台词外写明说话者。同期声写清本单元需要的对白、环境声和动作音效及发生镜头、动作节点或时段；确定不需要的声音明确“不需要”，尚未确定的内容作为代码块外待补项。确有音色参考需求才添加声音资产行，未调用则删行。

以下固定光线、字幕和音乐限制保留原文；摄影参数、受光和声音内容以有效分镜为准，不能由限制段反推或新增创作。

```text
资产参考：
人物使用名=@人物资产名，保持脸、发型、服装结构和身形比例。
场景使用名=@场景资产名，作为本镜头唯一场景，保持空间结构、材质和场景内实际光源。
道具使用名=@道具资产名，保持外观、数量、尺寸比例、材质和持握方式。
声音使用名=@声音资产名，作为对应人物 / 生物的稳定音色参考。

画面质感：……。

连续单镜头，……秒。

场景使用名，……景别，……mm，……运镜。开头处于……的清楚初始状态。人物空间站位关系。主体表演、动作及原台词。人物与场景实际光源的空间关系。动作或对白完成后形成……的稳定结束状态。

同期声：……。
光线规则：严格保持场景资产与已确认分镜中的光源、光向和明暗关系。人物、道具和背景不新增正面补光、镜头方向的柔光或额外轮廓光。不为看清人物脸部而提高整体曝光、提亮暗部或削弱阴影。人物脸部可以部分或完全处于阴影中。人物移动与既定光源变化造成的受光变化，按分镜正常呈现。

字幕限制：不要字幕，不将台词转写为画面文字，不添加标题或说明性文字。

音乐限制：不要音乐，不生成背景配乐或情绪铺底音乐。只保留已明确要求的对白、环境声和动作音效。
```
