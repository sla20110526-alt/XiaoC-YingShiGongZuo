# 专业顾问单元 Skill｜输出约定

## 一、专业顾问结果

完成顾问工作后，向提出问题的执行环节返回以下内容：

| 内容 | 约定 |
|---|---|
| 专业问题与使用场景 | 明确本次回答什么问题，以及结论用于项目中的什么工作。 |
| 专业结论 | 针对具体问题给出判断，区分资料支持的内容与分析推导。 |
| 主要依据 | 提供可定位的资料来源，说明主要结论与依据的对应关系。 |
| 适用条件 | 说明结论成立的前提及适用范围，结合问题注明相关年代、地域、行业或其他条件。 |
| 创作建议 | 将专业结论转化为当前执行环节可以采用的具体建议。 |
| 待核实内容 | 存在不确定性时，说明具体内容、对当前判断的影响及所需补充依据。 |

存在不同创作处理方式时，说明各自的适用条件及对当前创作的影响，供用户判断。

## 二、需要补充的信息

已有信息不足以开展判断时，返回具体补充问题，并说明：

- 需要补充什么信息或资料。
- 该信息影响本次工作的哪项判断。

补充问题应围绕当前任务，继承项目中已经明确的信息。

对于可以形成结论的部分，交付已有依据支持的结果；仍待核实的部分明确标注。

## 三、项目采用与成果引用信息

随专业顾问结果提供：

- 已有项目与任务标识。
- 本次专业问题及承接执行环节。
- 顾问成果和主要依据的可定位引用。
- 本次实际使用的相关专业 Skill 名称与版本（适用时）。

引用信息与本次实际使用的资料和能力保持一致，供资料与资产登记部按既定规范承接登记。

## 四、可复用方法的建设依据

顾问工作中形成可复用方法时，向专业能力建设单元提供：

| 内容 | 约定 |
|---|---|
| 解决的问题 | 说明方法针对哪类专业问题。 |
| 方法要点 | 提炼关键分析步骤、判断方法或查证方法。 |
| 适用条件 | 说明该方法适合哪些任务及使用前提。 |
| 来源与案例依据 | 提供方法来源、对应项目案例及可定位引用。 |
| 已有支持范围 | 说明哪些部分得到现有资料或案例支持。 |
| 待验证内容 | 说明推广到其他任务时仍需验证的部分。 |

上述内容作为新增或优化专业 Skill 的候选依据，由专业能力建设单元承接。

## 五、呈现方式

对话中优先呈现专业结论、对当前创作的影响、建议及必要的不确定性说明。

主要依据与相关内容对应呈现；详细资料通过可定位引用提供，供用户和承接执行单元按需查看。
